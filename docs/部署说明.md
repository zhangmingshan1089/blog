# 部署说明

面向 Typecho 1.3 + PHP 8.2 + SQLite 的单机部署。按顺序做，大概十分钟。

## 1. 前置

- 一个能跑 PHP 8.2 的空间（Nginx + PHP-FPM）
- Typecho 1.3.0 已装好，能进后台
- 数据库用 SQLite（`usr/xxx.db`），表前缀随意

## 2. 放文件

| 仓库路径 | 站点路径 |
|---|---|
| `theme/wbclean/` | `usr/themes/wbclean/` |
| `modules/drive/` | `drive/` |
| `modules/publish/` | `publish/` |
| `modules/moments/` | `moments/` |
| `modules/timeline/` | `timeline/` |
| `modules/danmaku/` | `danmaku/` |
| `modules/panel/` | `panel/` |
| `modules/music/` | `music/` |
| `modules/admin/` | 后台美化的 CSS/JS，可按需引入 |
| `modules/root/` | 站点根目录（`403.html` `404.html` `robots.txt`） |

放完在后台 **外观 → 启用** `wbclean`。

需要新建的运行时目录（**不要**提交到仓库）：

```
usr/uploads/        755
usr/cache/wbpage/   755，可写
music/uploads/      755，可写
drive/              755，可写
```

## 3. Nginx

```nginx
# 伪静态
location / {
    index index.php index.html;
    if (-f $request_filename/index.html) { rewrite (.*) $1/index.html break; }
    if (-f $request_filename/index.php)  { rewrite (.*) $1/index.php break; }
    if (!-f $request_filename)           { rewrite (.*) /index.php last; }
}

# 静态资源缓存：改了 CSS/JS 一定要升版本号，否则 12 小时内不生效
location ~* \.(css|js|webp|jpg|png|woff2)$ {
    expires 12h;
    add_header Cache-Control "public, max-age=43200";
}

# 后台与接口不要被整页缓存
location ~ ^/(admin|panel|publish|drive)/ {
    add_header Cache-Control "no-store";
}
```

PHP 需要 `fileinfo`、`gd`（封面缩略图）、`pdo_sqlite`。

## 4. 主题设置

后台 **外观 → 主题设置** 里有：

- 首页大标题 / 副标题（留空会用默认文案）
- 背景图（不传则用主题自带的 `assets/hero-bg.*`）
- 备案号、社交链接

首访默认是 `tech` + 浅色，访客切换后记在 `localStorage`：

| key | 值 |
|---|---|
| `wb-style` | `tech` / `paper` / `butterfly` |
| `wb-theme` | `light` / `dark` |
| `wb-def2` | 默认配置迁移标记，只写一次 |

## 5. 缓存

主题自带整页缓存，落在 `usr/cache/wbpage/`，按 URL 哈希成文件，带 `X-WB-Cache: HIT/MISS` 响应头。

- 发布/修改文章、提交评论时自动清理
- 手动清理：删掉 `usr/cache/wbpage/` 下的文件即可
- HTML 里内联了 `style.css`，**改样式必须清这个缓存**

`?lite=1` 走精简模式：不内联 CSS，改成 `preload` 外链，主文档 185KB → 99KB，适合跨境慢链路。

## 6. 安全

开源仓库里**不含**任何部署通道密钥、数据库、上传文件。自己部署时注意：

- 后台路径别用 `/admin/`，Typecho 支持自定义
- `drive/` 首次访问会让你设管理员密码，只存 `password_hash`，忘了就删 `drive/.passwd` 重设
- 如果自己加了"远程写文件"的调试接口，记得用随机 key 并随用随删
- `modules/admin` 里的后台美化是前端资源，不含权限逻辑

## 7. 常见坑

**样式全丢、页面横向溢出**
`$this->options->themeUrl()` 在 Typecho 里是「echo 型」方法，直接调用会把 URL 打到页面上、返回 null。取主题目录请用：

```php
$cssBase = rtrim((string)$this->options->siteUrl, '/') . '/usr/themes/wbclean';
```

**手机上顶栏白底白字**
`@media(max-width:767px)` 里若把 `.topbar` 背景写成 `var(--paper) !important`，会盖掉 `tech` 风格的深色玻璃。要么给 `html[data-style="tech"] .topbar` 也加 `!important`，要么别用 `!important`。

**切了风格没变化**
`localStorage` 里存着旧值。无痕窗口验证，或清 `wb-style` / `wb-theme`。

**证书不含 www**
`https://www.你的域名/` 会直接失败。要么给证书加 SAN，要么统一用不带 www 的地址。
